This repository is intended to be a code sharing and collaboration platform for all the members of the ISC Pacific Bluefin Working Group (PBFWG) that are working on testing the MSE TAC calculation. It is not for management purposes.

##Generating the TAC
This repository provides workflow developed by the ISC PBF WG to generate a TAC for PBF fleet segments (EPO, WCPO small, WCPO large) given the output of the latest ASPM-R+ estimation model (EM), a specified candidate MP, and either an WCPO:EPO  baseline fisheries impact ratio calculated using the selectivity at age and relative apical F from 2015-2022, which leads to approximately an 80:20 WCPO:EPO impact, or a 70:30 WCPO:EPO impact. For details see [Tommasi et al. 2026] (https://isc.fra.go.jp/pdf/PBF/ISC26_PBF_1/2026_ISC_PBFWG-1_01.pdf) . To calculate the TAC for each MSE candidate HCR and the Newport HCR, clone this repository and use the script MP_generation.R. with epoi set at either 20 or 30,depending on the fisheries impact you want to specify.

##Workflow to Generate New Forecast File for MP Calculation given Specified Impact
To calculate a new MP TAC given a new impact different from 70:30 or 80:20, one has to provide the EM with a new forecast file detailing a new allocation of the apical F between WCPO and EPO fleets that would lead to the desired impact given selectivity at the 2015-2022 and constant biological parameters. This is done by following the method of [Tommasi and Lee 2024] (https://isc.fra.go.jp/pdf/PBF/ISC24_PBF_1/2024_ISC_PBFWG-1_10.pdf), which found a relationship between the change in WCPO to EPO apical F from its 2015-2022 baseline and the resulting WCPO:EPO. For example, for the 70:30 WCPO:EPO impact ratio, it was found that the baseline 2015-2022 EPO RelF needed to be modified to have 6.5% more of the total apical F, and the WCPO RelF to have 6.5% less ([ISC 2025] (https://isc.fra.go.jp/pdf/ISC25/ISC25ANNEX08PBFMSEfinalreport_ERRATUM.pdf)). Note that while the RelF between the EPO and WCPO fleets is controlled by the chosen fisheries impact ratio, within the WCPO or EPO, the RelFs of the different WCPO (e.g. small vs. large) fleets remain proportional to those in the 2015-2022 baseline no matter the WCPO:EPO impact ratio used. The forecast file with the RelF needed to compute a 75:25 WCPO:EPO has already been developed and is on the PBFTAC repository. Just run the MP_generation.R script with epoi set at 25 to obtain the TAC for each candidate HCR.

Below we exemplify the workflow to generate a TAC based on a specified fisheries impact ratio using 78:22 WCPO:EPO as an example.

1.	Clone GitHub directory PBFTAC
2.	Create new EMs with forecast files that have relative Fs reflecting the new fisheries impact by running the new_forecast.R code. Make sure that you specify epoid = your specified impact, here we use epoid = 22.
3.	Generate a data frame with the new TACs for each of the candidate HCRs using the MP_generation. R script. Make sure that you specify epoi = your specified impact, here we use epoi = 22. Note that the HCRs are labelled 1 to 8 since they have the same shape/reference points as HCRs 1 to 8 in the MSE report, but they use a different impact. There is also an HCR labelled 17, this is the Newport HCR proposed by the JWG.

=======
This repository provides the code to calculate an example TAC for Pacific Bluefin Tuna fleet segments for each of the specified candidate management procedure given an ASPM-R+ estimation model output and the 2015-2022 relative F agreed upon by the IATTC-NC JWG on PBF management, adjusted to meet an ECPO:WCPO impact ratio of 30:70 for HCRs 9:16 and 18.
The repository is intended to be a code sharing and collaboration platform for all the members of the ISC Pacific Bluefin Working Group (PBFWG) that are working on testing the MSE TAC calculation. It is not for management purposes.
# Running the code
To calculate the TACs you need to clone this repository to your computer and then open the MP_generation.R script. At the start of the file you will specify on line 29 the EPO impact ratio to use (either 20 or 30). When you run the code the output is the TACout data frame, which specifies the TAC for candiate MPs 1-8, and 17 if you specified an epo impact of 20, or the TAC for candidate MPs 9-16, and 18 if you specified an epo impact of 30. Note that the HCRs in the TACout data frame are always labelled 1-8, and 17 even if run with th epo 30 impact ratio as the HCR shape is the same, only the impact ratio changes between MPs 1-8, 17 and MPs 9-16, 18.
